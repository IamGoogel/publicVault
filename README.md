# Mathematik und Physik – Lernnotizen (Obsidian-Vault)

## Zweck
Die Notizen sind Lernzusammenfassungen, die für die eigene Prüfungsvorbereitung entstanden sind und hier zum Nachschlagen geteilt werden. Sie ersetzen weder die Vorlesungen noch Lehrbücher. Geteilt werden ausschließlich eigene Zusammenfassungen; Lehrmaterialien Dritter sind nicht Teil dieses Repositories.

## Keine Gewähr auf Richtigkeit
Die Notizen sind private Zusammenfassungen und keine offiziellen Lehrmaterialien. Trotz sorgfältiger Prüfung besteht **keine Garantie auf absolute Richtigkeit** der Inhalte.

## Fehler melden
Fehler oder Unklarheiten bitte als [**Issue**](https://github.com/IamGoogel/publicVault/issues/new) in diesem Repository melden, mit Angabe der betroffenen Notiz und einer kurzen Beschreibung des Fehlers.

## Darstellung
Der Ordner ist ein **Obsidian-Vault**: Markdown-Dateien mit Obsidian-spezifischer Syntax.

- Interne Verweise sind als `[[Wikilinks]]` gesetzt. In Obsidian sind sie anklickbar, in der GitHub-Ansicht erscheinen sie nur als Klartext.
- Formeln sind in LaTeX geschrieben (`$...$` bzw. `$$...$$`). Obsidian stellt sie zuverlässig dar, die GitHub-Weboberfläche nur eingeschränkt.
- Callout-Boxen (`> [!note]`, `> [!warning]` usw.) sind ebenfalls Obsidian-spezifisch und erscheinen auf GitHub nur als einfaches Zitat.
- **Empfehlung:** Für die volle Darstellung den Ordner in [Obsidian](https://obsidian.md) öffnen (kostenlos, Download nötig) statt nur über die GitHub-Weboberfläche zu lesen.
