# Newtonsche Axiome

#exphy1 #mechanics #dynamics #atomic

| Axiom | Aussage |
|---|---|
| **Newton I** (Trägheit) | ohne Kräfte: Ruhe oder gleichförmige Bewegung |
| **Newton II** | $\dot{\mathbf p}=\mathbf F$, bei konstanter Masse $\mathbf F=m\mathbf a$ |
| **Newton III** | $\mathbf F_{21}=-\mathbf F_{12}$ (actio = reactio) |

Luftkissenschiene: Reibung ≈ 0 ⇒ $a=0$, $v=$ const. Ein Körper braucht keine Ursache für Bewegung, nur für **Änderung** des Bewegungszustands.

- $\dot{\mathbf p}=\mathbf F$ ist eine **Differentialgleichung**; Integration liefert die Bahn.
- Newton I = Sonderfall von Newton II für $\mathbf F=0$.
- Einheit: $1\,\mathrm N=1\,\mathrm{kg\,m\,s^{-2}}$.

> [!warning] Actio/Reactio heben sich nicht auf
> Sie greifen an **verschiedenen** Körpern an.
