# Minkowski-Diagramm

#exphy1 #mechanics #relativity #atomic

Achsen: $x$ nach rechts, $ct$ nach oben. Ereignis = Punkt, Körperbahn = **Weltlinie**; ruhend: senkrecht, Geschwindigkeit $v$: $x=(v/c)\,ct$.

- **Lichtgeraden** $ct=\pm x$ (Steigung $\pm1$) in jedem Inertialsystem; keine Weltlinie ist flacher. Sie trennen zeitartige von raumartigen Ereignissen ([[Invarianter Abstand und Kausalität]]).
- **Zweites System $K^\prime$:** $ct^\prime$-Achse = Weltlinie von $O^\prime$: $x=\beta ct$. $x^\prime$-Achse: $ct=\beta x$. Beide um $\tan\alpha=\beta$ geneigt, spiegelbildlich zur Lichtgeraden.
- Einheiten von $K^\prime$ sind im Diagramm um $\gamma\sqrt{1+\beta^2}$ länger (für $u=0{,}6c$ ≈ 1,46).
- **Ablesen:** Parallelen zu den **schiefen** Achsen.

```
 ct ▲   ct'  ╱     Lichtgerade ct = x
    │    ╲  ╱
    │     ╲╱  x'
    │     ╱╲────
    └──────────▶ x
```
**Beispiel:** $P=(x,ct)=(3{,}5;\,4{,}5)$, $u=0{,}6c$: $x^\prime=1{,}25(3{,}5-0{,}6\cdot4{,}5)=1$, $ct^\prime=1{,}25(4{,}5-0{,}6\cdot3{,}5)=3$; $s^2=4{,}5^2-3{,}5^2=8=3^2-1^2$ ✓.
