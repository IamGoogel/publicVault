# Mächtigkeit und Abzählbarkeit

#maphy1 #foundations #set-theory #atomic

| Begriff             | Definition                                                         |
| ------------------- | ------------------------------------------------------------------ |
| gleichmächtig       | es gibt eine [[Injektiv, surjektiv, bijektiv\|Bijektion]] $M\to N$ |
| abzählbar unendlich | gleichmächtig zu $\mathbb N$                                       |
| abzählbar           | endlich **oder** abzählbar unendlich                               |
| überabzählbar       | nicht abzählbar                                                    |

**Ergebnisse.**
- Bsp.: $\mathbb N,\mathbb Z,\mathbb Q$ sind gleichmächtig.
- Satz: Eine abzählbare Vereinigung abzählbarer Mengen ist abzählbar.
- Satz: $\mathbb R$ ist **überabzählbar**.

```
Z:  1  2  3   4  5   6  7 ...
    0  1 -1   2 -2   3 -3 ...
Q über die "Höhe" |p|+q  (p/q gekürzt, q>0):
 Höhe 1: 0     Höhe 2: 1, -1     Höhe 3: 2, 1/2, -1/2, -2   ...
```

> [!tip] Beweisidee $\mathbb Q$
> Jede Höhe enthält endlich viele rationale Zahlen ⇒ $\mathbb Q$ ist abzählbare Vereinigung endlicher Mengen.
