# Polarkoordinaten

#vorkurs #vorkurs-physik

> [!definition] Ebene Polarkoordinaten
> $\varrho$ ist der Abstand zum Ursprung, $\varphi$ der Winkel zur $x$-Achse; $\varrho \in [0,\infty)$, $\varphi \in [0, 2\pi)$:
> $$\vec{r} = \begin{pmatrix} x \\ y \end{pmatrix} = \varrho\begin{pmatrix} \cos\varphi \\ \sin\varphi \end{pmatrix}, \qquad \varrho = \sqrt{x^2 + y^2}$$
> Hält man eine Koordinate fest, entsteht eine Koordinatenlinie: $\varrho = \text{konst.}$ ergibt einen Kreis um den Ursprung, $\varphi = \text{konst.}$ eine Halbgerade. In kartesischen Koordinaten wären es dagegen Geraden; deshalb spricht man von krummlinigen Koordinaten.

> [!note] Kontrolle des Betrags
> $|\vec{r}| = \sqrt{\varrho^2\cos^2\varphi + \varrho^2\sin^2\varphi} = \varrho\sqrt{\cos^2\varphi + \sin^2\varphi} = \varrho$, siehe [[Trigonometrischer Pythagoras]].
