# Graphisches Ableiten

#vorkurs #vorkurs-physik

> [!definition] Graphisches Ableiten
> Man liest die Steigung der Kurve $x(t)$ ab und trägt sie als Funktionswert von $v(t)$ in das darunterliegende Diagramm ein:
> - horizontale Tangente → $v = 0$
> - Gerade mit positiver Steigung → konstanter positiver Wert
> - Knick in $x(t)$ → Sprung in $v(t)$
> - Maximum oder Minimum von $x$ → Nullstelle von $v$
> - Wendepunkt von $x$ → Extremum von $v$
> Kontrolle: Wo $x(t)$ wächst, muss $v(t)$ oberhalb der Achse liegen, und besondere Punkte beider Kurven stehen senkrecht untereinander.

> [!example]- Sprung von einer $20\,\mathrm{m}$ hohen Klippe
> $$s(t) = h - \tfrac{1}{2} g t^2$$
> Setzt man $s(t) = 0$, erhält man die Fallzeit $t = \sqrt{2h/g} = 2\,\mathrm{s}$ (mit $g \approx 10\,\mathrm{m/s^2}$). Die Geschwindigkeit beim Aufprall ergibt sich erst durch Ableiten:
> $$v(t) = -g\,t \;\Rightarrow\; -72\,\mathrm{km/h}$$
> Für Ableitungen gibt es drei gleichwertige Schreibweisen, jeweils die Steigung der vorigen Größe:
> $$v = s' = \frac{ds}{dt} = \dot{s}, \qquad a = v' = \frac{d^2 s}{dt^2} = \ddot{s}$$
