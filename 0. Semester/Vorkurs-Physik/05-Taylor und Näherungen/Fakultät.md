# Fakultät

#vorkurs #vorkurs-physik

> [!definition] Fakultät
> $n!$ ist das Produkt aller natürlichen Zahlen von $n$ bis $1$, z. B. $3! = 3\cdot 2\cdot 1$.

> [!example]- Beispiele (Kehrwerte)
> $$\frac{1}{1!} = \frac{1}{1} = 1$$
> $$\frac{1}{2!} = \frac{1}{2\cdot 1} = \frac{1}{2}$$
> $$\frac{1}{3!} = \frac{1}{3\cdot 2\cdot 1} = \frac{1}{6}$$
