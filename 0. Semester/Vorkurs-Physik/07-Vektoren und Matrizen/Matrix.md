# Matrix

#vorkurs #vorkurs-physik

> [!definition] Matrix
> Eine Matrix ist mehr als eine Zahlentabelle: Sie ordnet jedem Vektor einen anderen Vektor zu (etwa dasselbe Dreieck im gedrehten und im ungedrehten Koordinatensystem).
> Hat eine Matrix $n$ Zeilen und $m$ Spalten, ist ihr Format $n \times m$. Das Element $m_{ij}$ steht in der $i$-ten Zeile und $j$-ten Spalte — zuerst die Zeile, dann die Spalte.

> [!satz] Rechenregeln
> Bei gleichem Format rechnet man Eintrag für Eintrag:
> $$(A \pm B)_{ij} = a_{ij} \pm b_{ij}, \qquad (\lambda A)_{ij} = \lambda\,a_{ij}$$
> Ein Spaltenvektor hat das Format $3\times1$, ein Skalar $1\times1$. Das Produkt zweier Matrizen behandelt [[Matrixmultiplikation (Vorkurs)|Matrixmultiplikation]].
