# Betrag einer komplexen Zahl

#vorkurs #vorkurs-physik

> [!definition]
> Der **Betrag** von $z = u + iv$ ist
>
> $$|z| = \sqrt{u^2 + v^2}$$
>
> In der Skizze ist $r = |z|$ der Abstand zum Ursprung. Herleitung über $z\bar{z}$: [[Komplexe Konjugation]].

> [!example]+ Beispiel
> $z = 4 + 2i$:
>
> $$|z| = \sqrt{u^2 + v^2} = \sqrt{20}$$
