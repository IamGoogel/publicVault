# Komplexe Einheitswurzeln

#vorkurs #vorkurs-mathe

> [!definition]
> Die $n$-te Wurzel einer komplexen Zahl $z = r\,e^{i\varphi}$ berechnet man mit der [[Polarform]]. Verschiedene Lösungen erkennt man nur, wenn man die Periodizität berücksichtigt:
>
> $$\sqrt[n]{z} = \sqrt[n]{r}\,\left(\cos\frac{\varphi + 2k\pi}{n} + i\sin\frac{\varphi + 2k\pi}{n}\right) = \sqrt[n]{r}\,e^{i\frac{\varphi + 2k\pi}{n}}, \quad k = 0, 1, \ldots, n-1 \text{.}$$

> [!example]- Beispiel
> Gesucht sind alle dritten Wurzeln von $z = 8 = 8(\cos 0 + i\sin 0)$:
>
> $$z_0 = 2, \qquad z_1 = 2\left(\cos\tfrac{2\pi}{3} + i\sin\tfrac{2\pi}{3}\right), \qquad z_2 = 2\left(\cos\tfrac{4\pi}{3} + i\sin\tfrac{4\pi}{3}\right) \text{.}$$
>
> Probe: $z_k^3 = 8\big(\cos(2k\pi) + i\sin(2k\pi)\big) = 8$ für $k = 0, 1, 2$.
