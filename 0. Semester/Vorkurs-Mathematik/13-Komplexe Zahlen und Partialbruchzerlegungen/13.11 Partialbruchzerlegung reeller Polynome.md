# Partialbruchzerlegung reeller Polynome

#vorkurs #vorkurs-mathe

> [!satz] Partialbruchzerlegung über ℝ
> Ein reelles Polynom lässt sich über $\mathbb{R}$ faktorisieren, indem man es über $\mathbb{C}$ zerlegt ([[13.8 Fundamentalsatz der Algebra]]) und konjugierte Nullstellen ([[13.10 Komplexe Nullstellen reeller Polynome]]) paarweise multipliziert:
>
> $$Q(x) = a \cdot \prod_{j=1}^{k} (x - t_j)^{n_j} \cdot \prod_{j=1}^{l} \left(x^2 + b_j x + a_j\right)^{m_j}, \qquad \sum n_j + 2 \sum m_j = n \text{,}$$
>
> wobei die quadratischen Faktoren keine reellen Nullstellen haben. Für $\deg P < \deg Q$ gilt dann
>
> $$\frac{P(x)}{Q(x)} = \sum_{j=1}^{k} \sum_{\nu=1}^{n_j} \frac{a_{j\nu}}{(x - t_j)^\nu} + \sum_{j=1}^{l} \sum_{\nu=1}^{m_j} \frac{b_{j\nu}\,x + c_{j\nu}}{\left(x^2 + b_j x + a_j\right)^\nu} \text{.}$$

> [!example]- Beispiel
> $$\frac{(1+x)^2}{x\,(1+x^2)} = \frac{A}{x} + \frac{Bx + C}{x^2 + 1} = \frac{Ax^2 + A + Bx^2 + Cx}{x\,(x^2+1)}$$
>
> Daraus folgt $x^2 + 2x + 1 = (A+B)x^2 + Cx + A$. Der Koeffizientenvergleich ergibt $A + B = 1$, $C = 2$, $A = 1$, also $B = 0$:
>
> $$\frac{(1+x)^2}{x\,(1+x^2)} = \frac1x + \frac{2}{x^2 + 1} \text{.}$$
